# 星际防线 STARLINE

单文件竖屏弹幕射击游戏。1000 个关卡 + 无尽深空，26 款皮肤，8 种语言。

作者：浩赟 · 开放平台 [github.com](https://github.com)

## 直接玩

用浏览器打开 `index.html` 即可，无需安装、无需联网资源，纯前端 Canvas 实现。

## 玩法

- 手机：手指在屏幕任意位置拖动，飞船跟随移动
- 电脑：WASD / 方向键移动
- 射击自动进行，你只负责躲弹
- 炸弹：右下角按钮（键盘 B），清空全场敌弹
- 暂停 P，静音 M

新手建议：进设置把难度改成「简单」，先打第 1 关熟悉手感。

## 关卡与进度

- 共 1000 关，前 21 关为手工主题，之后程序化生成
- 每关 4 波敌人，第 4 波为 BOSS
- 通关自动解锁下一关；也可花 100 金币提前解锁
- 每关最多复活 5 次，每次消耗金币

## 金币与皮肤

- 金币来源：击杀掉落、过关奖励、看广告领 100 金币
- 商店 26 款皮肤，价格从 0 到 3400 金币
- 新手推荐先买「匕首」（280 金币），移速更快

## 广告说明

广告为游戏内模拟动画，未接入任何真实广告平台，看完直接发放 100 金币，不涉及第三方。

## 存档

金币、已购皮肤、关卡进度、最高分、语言与设置项保存在浏览器 localStorage（键 `starline.save.v4`，另有 `.bak` 备份）。退出浏览器或游戏后不会丢失。设置页支持导出 / 导入存档 JSON。

## 语言

简体中文、English、日本語、한국어、Español、Français、Deutsch、Русский，在「设置 → 语言」切换。
